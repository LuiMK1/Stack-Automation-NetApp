# ONTAP Primary Setup

The launch form does not show run or skip switches. Leave a section blank and that task stays skipped. Enter values and that task runs.

Required fields are the agent, cluster management address, and password. The username defaults to admin. You can click Next and Finish with only those filled in.

Storage failover, cluster HA, cluster-management auto-revert, spare-disk zeroing, CDP, LLDP, and default broadcast-domain cleanup do not have their own fields. Every launch discovers the cluster nodes, enables storage failover on each node, and sets cluster HA only when that discovery finds exactly two nodes. It also finds the cluster management interface and enables auto-revert on it, zeros spare disks, and enables CDP and LLDP. It deletes an autogenerated Default broadcast domain when that domain is in the Default IPspace, its name starts with `Default-`, and it contains no cluster or node-management port.

Node configuration is one table. Each row is one node, so the node name is entered once. That row has separate columns for the service-processor address, data ports, aggregate name, and disk count. One aggregate is created on that node. To skip the service-processor, aggregate, and data-port tasks, delete every row. A blank row still counts as a row, and Finish stays disabled until that row is filled in or deleted.

| Filled in | Task that runs |
| --- | --- |
| Cluster name and location | Update cluster location |
| Node configuration rows | Configure each node's service processor, disable flow control on its data ports, discover the disk class, and create one aggregate on that node |
| DNS domain and DNS servers | Configure DNS |
| NTP servers | Configure NTP |
| Cluster name and timezone | Set the timezone |
| AutoSupport mail settings | Configure AutoSupport on the nodes discovered from the cluster |
| Legacy license keys or NLF contents | Add licenses |
| `true` or `false` in the FIPS dropdown | Set SSL FIPS mode. Leave the dropdown blank to leave cluster FIPS unchanged |
| SNMP contact, location, and SNMPv3 user | Configure and enable SNMP. With authentication `none`, the authentication password, privacy protocol, and privacy password stay hidden and privacy is set to `none`. Choosing `md5`, `sha`, or `sha2_256` shows the authentication password and privacy protocol. The privacy password stays hidden while privacy is `none`, and appears for `des` or `aes128`. FIPS mode shows both passwords. Community and traphost are optional and apply only when FIPS is blank or `false` and that field is filled |
| Login banner text | Set the login banner |
